# personal-finance-budgeting-model
An Excel-based personal finance and budgeting model for college students.
Personal Finance & Budgeting Model for College Students
📌 Project Overview

The Personal Finance & Budgeting Model for College Students is an Excel-based financial planning project that helps students manage income, expenses, budgets, savings goals, and monthly financial performance.

The project shows how Excel can serve as a practical tool for personal financial planning and analysis.

🎯 Objectives
Track monthly income and expenses
Create category-wise budgets
Compare budgeted expenses with actual expenses
Calculate monthly savings and savings rate
Set and monitor financial goals
Perform what-if analysis
Visualize financial information through an interactive dashboard
🛠️ Tools Used
Microsoft Excel
Excel formulas and functions
Data validation
Conditional formatting
Charts and dashboard visualization
What-if analysis
📊 Project Features
1. Budget Planner

The Budget Planner compares planned expenses with actual expenses and calculates the variance.

Key calculations include:

Total Budget
Total Actual Expenses
Budget Variance
Monthly Savings
Savings Rate
2. Expense Tracker

The Expense Tracker records individual transactions using:

Date
Category
Description
Amount
Payment Method
Notes
3. Savings Goals

The Savings Goals section helps estimate how many months are required to reach different financial targets.

Example goals include:

Emergency Fund
Laptop Fund
Japan Study Fund
4. What-If Analysis

The What-If Analysis section evaluates how changes in income or expenses can affect monthly and annual savings.

5. Financial Dashboard

The dashboard provides a visual summary of:

Monthly Income
Monthly Expenses
Monthly Savings
Savings Rate
Expense Distribution
Budget vs Actual Expenses
📈 Key Excel Formulas

Some of the formulas used in the project include:

Total Expenses

=SUM(C7:C13)

Budget Variance

=B7-C7

Monthly Savings

=B3-C14

Savings Rate

=B16/B3

Remaining Savings Goal

=MAX(0,B2-C2)

Months Required

=ROUNDUP(E2/D2,0)

Annual Savings

=D2*12
